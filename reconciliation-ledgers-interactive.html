This diagram shows what you build and operate as a fintech processing payments via SEPA, Instant Payments, or card networks. Solid-border boxes = your systems (Pub/Sub, AlloyDB, Dataflow, etc.). Dashed-border boxes = external parties (bank systems, clearing infrastructure, customers) — you do not control these.

💳 Payment Initiation

USER REQUEST → VALIDATE → IDEMPOTENCY KEY → PUBLISH EVENT → RETURN 202 ACCEPTED

📒 Ledger & Event Processing

PUB/SUB EVENT → IDEMPOTENCY CHECK → ATOMIC LEDGER WRITE → STATE UPDATE → BANK SUBMISSION

🏦 Settlement & Bank Processing

SEPA MESSAGE → BANK BATCH → PAIN.002 STATUS → WEBHOOK CALLBACK → STATE UPDATE (DO NOT REVERSE YET)

🔍 Reconciliation (Recon-Gated)

CAMT.053 STATEMENT → PARSE → MATCH LEDGER → CONFIRM OR FLAG → RECON-GATED REVERSAL
